# 当前实际检测与预测流程（v0.4.0-alpha.2）

本页描述导出源码的运行路径；README有完整Mermaid图。
入口：`forecast.py predict` → SDK环境的 `run_fast_structure.py`，GPU检测独立进程。
预测器不读取评分人工框；评分在因果输出冻结后进行。

## 1. RAW、过滤与整机ROI

原始事件是(x,y,t,p)。默认每33333微秒一批，约30Hz；不把压缩视频当事件。
解码有界缓冲保留完整事件，不靠删大包提速。活动噪声过滤阈值10ms。
过滤后的二值占用图供当前KLT，原生ON/OFF伪彩图供NN；没有G通道灰度重建。
几何使用ROI内最近20ms原生事件；周期使用所选像素的原始时间，两者不是同一窗口。

单类ONNX整机检测约每3个源时刻刷新。其余时刻用双向KLT位移更新ROI；
少于6个可靠点、前后不一致、过大位移或出画时拒绝当作当前检测。
异步旧NN结果需要当前图像运动接续。
候选中，已有合格几何且当前KLT至少12点、散布合格才可减少重复NN，最多0.3秒强制刷新。
事件、当前轴线与周期仍按源时刻处理；不无限惯性续接。

代码：`fast_raw_reader.py`、`live_decode.py`、`live_worker.py`、`run_fast_structure.py:track`。

## 2. 背景抑制、拆粘连与计算桨心

ROI分别统计ON/OFF、平滑、取共同支持、抑制弱计数，再做阈值与小尺度形态学处理。
当前弱计数门槛2、平滑支持门槛4，不是任意距离的通用最佳阈值。
轮廓先判断线状退化；非线轮廓由真实弧点拟合椭圆。
凹曲率异常产生粘连拆分候选，切开产生的弦不能作为真实边界。
覆盖、残差、尺寸、不确定性、视场完整性与周围事件支持共同筛选。

**桨心是合格椭圆的几何中心，并非神经网络单独识别桨心。**
短弧未必足以确定完整椭圆；条件差时只更新可观测方向或拒绝。
模板只引导搜索真实弧，不自己画椭圆后当检出。

代码：`fast_structure_front.py`、`rotor_geometry.py`、`curvature_split.py`、
`shared_arc_recovery.py`、`partial_arc_information.py`、`src/event_drone_forecast/geometry.py`。

## 3. 五圆共享模型与可见分支

共享图像模型：`p_i = c + A r_i`。c是机体参考中心，r是固定四点模板，A是二维仿射形变。
这是弱透视近似，未标定物理尺寸。直接观测点与模型条件补点分开记录。

| 当前证据 | 更新逻辑 | 仍未知的内容 |
|---|---|---|
| 四个独立合格桨心 | 连续确认后建立/更新共享模板、中心与轴 | 真实重心、尺度和完整三维姿态 |
| 三个非共线中心 | 近期模板条件下补第四点 | 隐藏点不是新观测，隐藏转速不补造 |
| 两个非扁平中心 | 秩4部分信息更新六维仿射状态 | 两点无法唯一确定三维平面 |
| 近侧视/高事件线 | 当前PCA/线段、秩1轴线约束和短时续接 | `axis_only`不代表测出恰好两个电机；法线符号有向上先验 |
| 一点、零点、出画 | 缺测、过期、失锁与重捕获 | 不保证一帧清晰后永久成功 |

侧视预算模式中约10Hz重搜完整桨盘，其间更新当前轴线，桨数记为未解析，不能写成“两桨检测成功”。
四桨波动而机体中心不动时，A吸收形变，c负责平移；需要合格中心约束，
不将每个桨摆动都累加成整机位移。模型失锁时该分离仍可能失败。

代码：`five_circle_model.py`、`continuous_five_circle.py`、`live_structure_bridge.py:QualifiedCenter`。

## 4. 一个位置/速度状态；纠正框重定位假运动

一个四维位置/速度状态维护整机运动。合格几何中心与整机中心按相关性保守融合。
默认没有v7传统位置/加速度并行预测器。

候选复用已经算出的KLT位移修正速度，从短时合格速度历史估计净加速度。
不新增一次光流或第二个位置KF。
局部框变完整框时，框中心校正不等于无人机瞬时位移：
只有当前可靠NN、重叠/包含及可靠点运动同时满足，才用当前位移纠偏；
弱框、旧NN、无点与无界框增长仍拒绝。
可选相似变换在参考中心评价位移，减轻旋转/尺度造成的平移偏差，不是完整三维姿态恢复。

代码：`shared_image_motion.py`、`live_local_flow.py`。

## 5. 周期 → 相对推力输入

默认固定种子保留25%像素，所选像素保留全部原始时间事件，
在60–1200Hz范围进行周期一致性、空间投票和共同闪烁筛选。
有合格桨盘时分配桨盘频率；侧视可使用条件成立的局部/整机代表频率。
最强峰可能是谐波，纯事件数不是RPM。

输入 `u = ρ n`，`ρ = f²/f₀²`，n为合格当前图像法线。
这不是独立转速真值或牛顿推力。叶片数/谐波不明时不能直接称机械RPM。
轴可靠但周期短缺时，旧幅值最多持有0.12秒，并用当前轴；
不刷新周期年龄、不参与增益学习或已知输入积分，不填隐藏桨RPM。
按槽位归一化、空间相位FFT仍是可选实验，最新联合成绩未默认启用。

代码：`live_pixel_axis.py`、`live_frequency_pixels.py`、`visibility_period.py`、
`axis_amplitude_bridge.py`、`shared_phase_fft.py`。

## 6. 二力有效模型 → 未来位置 → 在线反馈

图像域模型：`a = k u + d`。k为有效像素响应，d为未知合项，
可吸收重力、风/阻力、投影/尺度及未建模误差，不是分别测出这些力。
质量、桨径、推力系数和真实风速不能仅据此分别辨识。

基线保留FastForceResponse。候选用最近成熟历史残差更新，
同一时间窗先从实测速度变化扣除已知输入积分，再估计d；
避免拿当前推力去减过去平均加速度。
k只在历史、激励和信噪比门槛满足时学习。
切向约束 `t⊥n → tᵀa=tᵀd` 只更新d的一个可观测分量；
沿法线未知项仍不确定，同一流已被完整二力更新使用时不重复计证据。

候选净加速度条件外推：
`p(h)=p+h v+τ[h+τ expm1(-h/τ)]a`，当前τ=0.35秒。
这是条件均值，不表示重力会衰减；基线外推保留。
周期失效时允许受限短保持/图像净加速度回退，来源分别标明。
新实际观测到达后，只用已成熟历史残差修正参数，不读未来人工真值。
只能响应已经可见的变化，不能预知尚未出现的新控制指令。

代码：`fast_force_response.py`、`responsive_force.py`、
`flow_force_balance.py`、`projected_unknown_force.py`。

## 7. 输出、算力优化与配置边界

每个源时刻均保存，包括无效预测。输出含整机位置、直接/隐藏桨心、几何模式、
周期/旧幅值来源、预测资格、0.1/0.2/0.4秒坐标、计时和模型/源码哈希。
源30Hz、有效比例、当前观测Hz、计算能力FPS、完成延迟与首结果等待分开。
视频30FPS不是运行FPS。

计算优化包括有界解码预过滤重叠、ON/OFF计数与占用图共享、相同有限差分的JIT椭圆不确定度、
等价薄线统计融合、几何/周期调度、延迟渲染。
AVX2是合法本机SDK头文件的本地实例化，不包含SDK源码或二进制。
有限回放可延后循环GC并恢复，尚未验证无限流内存稳定。

| 入口 | 行为 |
|---|---|
| `forecast.py predict --profile baseline` | 保留alpha.1启动选项；默认不启用新候选组合 |
| `--profile candidate` | target-candidate＋rigid-motion＋tangent-disturbance＋structure-guided-nn |
| `--sdk-avx2` | 另外启用本地构建SDK实例；需AVX2和合法兼容SDK |
| `--current-nn-on-loss` | KLT失败时用当前NN，迁移录像测试另行启用 |
| `--kinematic-control` | 显式额外传统对照，默认关闭 |

底层 `--target-candidate` 本身不包含rigid/tangent/guided/AVX2；公开启动器补齐前三者。
默认计算优化保留等价原路径 `--reference-compute`。
新基线也包含主干修复，不能称逐字运行旧版ZIP；旧ZIP另存保留。
