# 方法、可观测性与项目贡献

## 五圆是图像几何先验

一个机体参考点与四个桨盘组成简化模型。首次四个当前合格中心建立共享图像模板，
随后采用 `p_i = c + A r_i` 六维弱透视/仿射状态。它不等于完整三维姿态、已知机架尺寸或真实质心。

| 当前证据 | 更新内容 | 不应推出的结论 |
|---|---|---|
| 四个合格当前桨心 | 初始化/更新同一共享模板 | 所有场景都能识别四个物理电机 |
| 三个非共线当前桨心 | 结合近期模板条件更新、推断缺点 | 三点在任意透视下唯一恢复第四点 |
| 两个非扁平当前中心 | 四维部分信息，保留未观测方向的不确定性 | 两点唯一确定三维平面 |
| 近侧视/线状支持 | 无符号图像轴线，短时保留模型 | 无人机速度方向就是机体法线 |
| 一点/零点/出画 | 允许失锁，拒绝假观测 | “一桨不可能出现”或一帧成功后永不失锁 |

短弧法线约束只修正当前可观测方向；真实弧恢复还需强事件点、覆盖、拟合、面积/周围环带支持。
隐藏桨心仅为模型估计，不重新喂给检测器当观测，也不填为测得转速。
至少两个独立当前中心支持的合格三桨可续接近期引导；轴线/两点/全先验反馈不刷新引导年龄。

## 条件周期与二力反馈

物理分支使用图像空间有效模型：

`a_image = k * u + d`

u由相对闪烁频率平方和图像法线形成；k是有效像素增益；d吸收重力、气动、
投影、尺度、增益误差和定位偏差。质量、桨径、推力系数与风速不能据此分别辨识。
也没有将事件数量直接标为牛顿推力。

在k暂时固定时，d从第一个成熟的0.2秒位移残差慢修正；k仍需足够历史和输入激励。
缺周期/姿态时最多保持120ms总加速度；持有不算新的当前推力观测。
推力轴的图像符号有向上先验，不是已测三维推力方向。速度还受历史运动与未知合力影响。

## 独立空间相位实验

五圆模型将当前事件拉回固定参考平面；对ON/OFF分别累计 `w*exp(2j*theta)`，
在100us箱、160ms窗内做复数FFT。门槛包括相位集中度、扇区支持及正反频谱至少3:1。
后者抑制静态非均匀图案共同闪烁。固定选择25%像素，保留所选像素全部时间事件，
不是无损保留全部事件。二叶片假设、谐波歧义和窗口延迟仍存在。

这个模块没有默认替换生产周期输入，也没有独立RPM真值或变向预测增益证明。

## 能主张的项目贡献

* 五圆共享状态与可见证据变化时的信息分工、退化处理和条件续接。
* 当前残弧、预测桨心和持有状态分离，减少模型自我确认。
* 物理输入/未知合力反馈与运动学对照、因果输出、失败实验和公开机制演示的完整组织。
* 对现有计算做等价批量化、共享统计，降低重复开销。

这些是工程实现和研究探索的贡献，不是对通用椭圆拟合、滤波、可见性切换、相位测速或扰动观察器的首创声明。
