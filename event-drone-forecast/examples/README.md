# 演示媒体

clear/side.webm来自自采train6约26–28秒/110–113秒已保存因果输出，30FPS只是播放时间。红点为当前中心、灰色为模型推断，黄色为条件物理预测。metrics.json为同起点历史开发结果，不是公开盲测。

latest_prediction_and_latency.png与metrics.json为alpha.2当前结果；clear/side视频、forecast_comparison和phase_tracks保留为历史演示，不是最新8秒预测视频。历史数字单独放在historical_alpha1_metrics.json。
