# v0.4.0-alpha.1 — 五圆事件无人机预测源码预览

首次整理当前五圆主线的公开源码：原生ON/OFF轮廓、四/三/两点与轴线的信息分工、
当前强弧约束、条件推力代理和未知合力反馈，输出未来0.1/0.2/0.4秒二维位置。

包含无需相机/数据/权重的合成演示、原始RAW配置入口、环境自检、兼容模型训练导出步骤、
少量演示媒体、同起点对照结果、第三方通知和来源清单。

同一侧视13目标的0.4秒平均误差53.90→52.72px；中位改善、尾部回退，仍落后于运动学控制。
短片平均计算能力约30–36FPS，不保证持续低延迟30FPS。空间相位FFT为独立实验，未默认替换周期链路。

这不是生产发行、真实RPM/牛顿推力验证或论文SOTA复现。参考模型、自采RAW、私有标注、SDK、
CUDA和作者DLL不随包提供；因此无法仅凭本ZIP复现真实飞行分数。
集成源码按AGPL-3.0-only发布，原MIT及第三方许可保留。

建议在GitHub标记为 **Pre-release**。数据/模型许可、真实测速/姿态标定和更广泛评估是后续工作。
