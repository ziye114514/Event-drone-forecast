# v0.4.0-alpha.2 — 2026-10-28

五圆与退化可见性主线的增量源码预览版，保留旧配置及alpha.1独立发布包。
本次解决局部框扩展为完整框时的速度污染，并增加同窗二力、可观测切向反馈与计算共享；
不是完整真实推力估计，也没有证明论文级泛化成绩。

## 改动

- 公开完整流程、四/三/两点/轴线更新分工，区分直接观测与模型推断。
- 复用已有KLT点位移；可靠NN重定位纠偏，不把框中心校正解释为真实瞬时速度。
- 同窗已知输入积分与未知项估计；短幅值桥最多120ms，旧幅值不学习增益、不自我续期。
- 可选刚体相似位移、法线切向未知项、结构指导NN刷新。
- JIT计数/占用图/椭圆不确定度、等价薄线融合和自适应周期调度。
- 自有SDK AVX2包装源码与可配置本地构建工具；无SDK头文件或编译二进制。
- 新增候选启动配置、重定位/短幅值机制反例检查、当前汇总与结果图。

目标尚未全面完成，数字不是独立真值测试、mAP或持续实时保证。

## 运行与兼容

默认profile baseline不自动启用候选；profile candidate明确启用新组合。
AVX2需额外本地编译；Numba/llvmlite为可选安装，SDK与GPU依赖外部配置。
参考ONNX权重未公开下载，完整历史分数尚不能由新用户开箱复现。
合成演示不需要SDK/权重/GPU。
